# MyShelf — 서비스 기획 개요

> 상태: Draft  
> 목적: 서비스 방향과 핵심 기능 정의

## 1. 서비스 소개

**MyShelf는 독서 경험과 마음에 남은 문장을 기록하고, 자신의 취향을 아카이빙하는 개인 독서·필사 서비스다.**

실제 책을 소유하거나 전자책을 읽는 공간이 아니라, 읽고 싶은 책을 발견하고, 독서 중 만난 문장을 수집하고, 직접 필사하며 자신만의 기록을 쌓아가는 공간을 지향한다.

아날로그 독서와 필사의 감성을 차용하되, 물리적인 제약을 그대로 재현하지 않고 웹의 장점을 활용한다.

## 2. 핵심 기능

### 2.1. 도서 탐색 및 독서 관리

- 외부 도서정보를 활용한 도서 검색 및 상세 조회
- 관심 있는 책을 Shelf에 등록하고 관리
- 모든 Shelf에 속한 책의 통합 조회
- 독서 상태 관리
    - `WANT_TO_READ`: 읽고 싶음
    - `READING`: 읽는 중
    - `READ`: 완독
- 실물 도서 소장 여부와 독서 진행률은 관리하지 않는다.

### 2.2. Shelf — 나만의 책장

Shelf는 사용자가 자유롭게 책을 분류하고 배치하는 보드다.

- 여러 Shelf 생성·수정·삭제
- 하나의 책을 여러 Shelf에 등록 가능
- Shelf별 책 배치 순서 자유롭게 변경
- 사용자가 관리하는 책은 하나 이상의 Shelf에 소속
- 특정 Shelf에서 책을 제거해도 다른 Shelf에 속한 동일한 책은 유지
- 별도의 전체 도서 삭제 기능 없이 각 Shelf에서 책을 관리
- 독서 상태는 Shelf와 독립적으로 관리
- 전체 도서 목록은 모든 Shelf에 속한 책을 중복 없이 조회하는 논리적인 범위이며, 별도의 Shelf로 관리하지 않음

### 2.3. 문장 수집 및 필사

**수집 문장**

- 독서 중 마음에 남은 문장을 수집한다.
- 직접 입력, 붙여넣기 등을 지원한다.
- 사진·OCR 등 다양한 수집 방식은 추후 검토한다.
- 수집만 하고 필사하지 않아도 된다.

**Paper — 디지털 필사 노트**

- Paper는 하나의 독립적인 필사 노트다.
- 하나의 Paper에 여러 문장을 이어서 필사한다.
- Paper별 배경 색상·질감 등 하나의 스타일을 적용한다.
- 페이지 구분이나 길이 제한 없이 스크롤 방식으로 사용한다.
- 필사 문장 하나는 하나의 Paper에 속한다.

**필사 문장**

- 수집한 문장을 사용자가 직접 타이핑한다.
- `DRAFT` / `COMPLETED` 상태를 가진다.
- 완료 여부는 사용자가 결정한다.
- 완료 후에도 오타, 내용, 서체 등을 수정할 수 있다.
- 서체·펜 스타일은 필사 문장별로 보존한다.
- 최초에는 기본 서체를 제공하며, 사용자가 펜·서체를 변경하면 이후 필사의 기본값으로 사용한다.
- 하나의 수집 문장에는 최대 하나의 필사 기록을 연결한다.

### 2.4. AI 도서 큐레이션

사용자가 새로운 책을 발견하거나 잊고 있던 책을 재발견하도록 돕는다.

**추천 방식**

- 주제 직접 입력: 사용자가 원하는 주제로 추천
- '네가 추천해줘': AI가 임의의 주제를 선정하여 추천
- 추천 권수 설정 가능 (기본 3~5권 수준)

**추천 처리**

1. AI가 주제에 맞는 도서 목록을 추천한다.
2. 실제 도서 API와 대조하여 도서정보를 검증한다.
3. 검증된 책만 추천 결과로 제공한다.
4. 기존 Shelf 등록 여부를 표시한다.
5. 새로운 책은 사용자가 선택하여 Shelf에 추가할 수 있다.

**다른 책 더 추천받기**

- 기존 주제를 유지한다.
- 이미 추천한 도서를 제외하도록 AI에 요청한다.
- 서버에서도 중복 여부를 검증한다.
- 기존 결과에 추가 추천 도서를 제공한다.

일반적인 동일 주제 재요청의 결과 동일성·다양성은 별도로 규정하지 않는다.

### 2.5. Collection — 필사 문장 큐레이션

- 사용자가 완성된 필사 문장들을 자유롭게 모으는 공간
- 서로 다른 Paper의 문장을 하나의 Collection에 담을 수 있다.
- 하나의 필사 문장을 여러 Collection에서 사용할 수 있다.
- `COMPLETED` 상태의 필사 문장만 등록할 수 있다.
- 구체적인 구성과 관리 경험은 후속 기획에서 논의한다.

## 3. 주요 설계 원칙

1. **취향 중심:** 독서량이나 성과보다 사용자가 발견하고 간직한 책과 문장에 집중한다.
2. **자유로운 구성:** 현실의 책장·노트에서 영감을 얻되 물리적 제약을 강제하지 않는다.
3. **사용자 주도:** 독서 상태, 필사의 완성 여부, 책과 문장의 분류는 사용자가 결정한다.
4. **신뢰할 수 있는 추천:** AI의 생성 결과를 검증된 도서정보와 연결한다.
5. **점진적 확장:** 핵심 독서·필사 경험을 먼저 구현하고 고급 기능은 필요에 따라 확장한다.

## 4. 후속 논의 사항

- 도서 중복 판단 및 마지막 Shelf에서 제거된 도서의 기록 처리
- 독서 상태 변경 규칙과 독서 날짜 기록 여부
- 문장 수집 방식 및 출처 관리
- Paper와 필사 문장의 편집·삭제·배치 정책
- Collection 상세 기능과 공유 정책
- AI 추천 개인화 및 추천 이력 관리
