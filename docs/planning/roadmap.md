# MyShelf 개발 로드맵

## 개발 방향

MyShelf는 Spring Boot 기반 백엔드 프로젝트로, 핵심 기능 구현을 우선하면서 인프라와 성능 개선 기술을 단계적으로 적용한다.

| 단계 | 주요 목표 | 상태 |
|---|---|---|
| 1. 백엔드 기반 구축 | 헥사고날 아키텍처, 회원가입, 로그인, JWT 발급 | 완료 |
| 2. 로컬 실행 환경 구축 | PostgreSQL, Docker, Docker Compose | 마무리 단계 |
| 3. CI/CD 구축 | GitHub Actions 중심의 자동화, Jenkins 기초 실습 | 예정 |
| 4. 핵심 기능 개발 | 도서 관리, 개인 서재, 독서 상태 및 기록 | 예정 |
| 5. 성능 및 비동기 처리 | Redis 캐싱, 비동기 처리, Kafka 적용 검토 | 예정 |
| 6. 운영 배포 및 검증 | 운영 환경 구성, 배포 자동화, 성능 및 안정성 검증 | 예정 |

JWT 발급은 구현했으며, 발급된 토큰을 이용한 보호 API 인증 처리는 향후 구현할 예정이다.

## 진행 원칙

- 핵심 기능과 테스트를 우선하며, 기술 도입 자체를 목표로 하지 않는다.
- Redis, Kafka 등은 실제 요구사항에 따라 적용 여부를 결정한다.
- 개발 순서는 학습 및 프로젝트 진행 상황에 따라 조정한다.
- 구체적인 작업과 진행 현황은 GitHub Issues 및 Pull Request에서 관리한다.
