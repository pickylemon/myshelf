# Feature 7 — 문장 수집 및 필사

> 상태: **예정** — 기존 Feature 6의 필사 계획을 Feature 7로 이동
>
> 선행 기능: 도서 관리 기반 구현. 세부 구현 순서는 배포·검증 후 조정
>
> 제품 정책: [서비스 기획 개요 — 문장 수집 및 필사](./myshelf-product-overview.md#23-문장-수집-및-필사)

## 1. 목표

등록한 도서에서 마음에 남은 문장을 수집하고, Paper에 직접 필사하는 기록 기능을 추가한다. Feature 5 종료 및 포트폴리오 1차 정리 범위에는 포함하지 않는다.

## 2. 예정 범위

- 도서와 연결된 문장 수집·조회·수정·삭제
- Paper 생성·조회·수정·삭제 및 필사 문장 연결
- 필사 문장의 DRAFT·COMPLETED 상태와 사용자 소유권 관리
- 도서의 Shelf 연결 변경과 독립적인 기록 보존 정책 검토

Paper 스타일·문장 편집 등 제품 방향은 기존 서비스 기획을 따른다. API·도메인·DB 계약과 테스트 범위는 구현 전에 구체화한다. Collection·사진/OCR 등 확장 기능의 포함 여부는 별도 결정하며, 이번 문서에서 구현 완료나 범위 확정을 의미하지 않는다.

## 3. 구현 전 확인할 사항

- 수집 문장·필사 문장·Paper의 연결 및 삭제 정책
- UserBook이 모든 Shelf에서 제거된 경우의 기록 조회·보존 정책
- 입력 길이, 출처 정보, 상태 변경과 편집 규칙
- Collection을 이번 Feature에 포함할지 후속으로 분리할지

## 4. 완료 기준

- [ ] 위 정책을 확정하고 API·DB·소유권 검증을 구현한다.
- [ ] 문장 수집 → Paper에 필사 → 편집·완료 흐름을 검증한다.
- [ ] 타인 기록 접근 차단과 연관 데이터 보존·삭제를 검증한다.
- [ ] 관련 테스트·빌드·CI와 문서를 확인한다.
